# ERFF Images

Upload photos, posters, and videos for the Elk Rapids Film Festival website.

## Folder Structure

- `2010/` - `2026/` — Festival photos organized by year
- `posters/` — Film poster images for the archive and voting pages
- `founders/` — Founder profile photos for the About page
- `site/` — Site assets (hero backgrounds, logos, etc.)

## Naming Suggestions

- Festival photos: `sunset-screening.jpg`, `jaws-lake-setup.jpg`
- Posters: `jaws-1975.jpg`, `grand-budapest-hotel-2014.jpg`
- Keep filenames lowercase with hyphens (no spaces)
